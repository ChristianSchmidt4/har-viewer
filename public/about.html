HAR Viewer

Fiddler-inspired HTTP Archive viewer

About This Project

This is a client-side HTTP Archive (HAR) viewer inspired by Fiddler. It allows you to inspect and analyze HTTP requests and responses captured in HAR files without uploading them to any server.

Key Features

  • Client-side parsing - your data never leaves your browser
  • Fiddler-like interface for examining HTTP traffic
  • Detailed request/response headers inspection
  • Performance timing analysis
  • Response content viewing
  • Export functionality
  • Fully responsive design

How to Use

  1. Generate a HAR file from your browser's developer tools
  2. Open the HAR Viewer application
  3. Upload your HAR file using the file selector
  4. Explore your HTTP requests in the detailed interface

HAR Format Support

This viewer supports the HAR 1.2 specification, which includes:

  • Request/response headers and bodies
  • Timing information (DNS, connect, send, wait, receive)
  • Performance metrics
  • Cache information
  • Cookies and query parameters
